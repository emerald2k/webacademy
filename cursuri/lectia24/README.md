# ⚛️ Lecția 24: Arhitectură de Stare & Formulare în React

Această lecție aprofundează gestionarea stării, formularele controlate, imutabilitatea tablourilor/obiectelor și implementarea unei aplicații complete de tip campanie promoțională.

---

## 🎯 Concepte Cheie & Exerciții

| Modul | Fișier | Concepte Acoperite |
| :--- | :--- | :--- |
| **Exercițiul 1** | `components/App1_Counter.jsx` | `useState`, `useEffect` (mount/update/cleanup), `useCallback` |
| **Exercițiul 2** | `components/App2_ControlledInput.jsx` | Controlled inputs, two-way data binding |
| **Exercițiul 3** | `components/App3_AuthForm.jsx` | `onSubmit`, `e.preventDefault()`, validare de formulare |
| **Exercițiul 4** | `components/App4_ProductList.jsx` | Imutabilitate (`[...arr, item]`, `.filter()`) |
| **Exercițiul 5** | `components/App5_ProductCRUD.jsx` | Create, Read, Update, Delete cu stare `editId` |
| **Exercițiul 6** | `components/App6_PromoCampaign.jsx` | Validare coduri unice, generare de premii, filtrare în timp real, statistici |

---

## 🚀 Cum se rulează

Modulul este integrat ca tab-uri în componenta principală [`App.jsx`](./App.jsx). 
Poate fi inclus în orice aplicație React/Vite sau rulat direct.
