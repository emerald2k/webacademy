# ⚙️ Tema 5: JavaScript Logic & DOM Manipulations

Exerciții de programare în Vanilla JavaScript centrate pe manipularea arborelui DOM, ascultători de evenimente și structuri de date.

---

## 🎯 Concepte Cheie

- Selectarea elementelor DOM (`document.querySelector`, `querySelectorAll`).
- Ascultarea și manipularea evenimentelor utilizator (`click`, `input`, `change`).
- Modificarea stilurilor și claselor CSS în mod dinamic (`classList.add`, `classList.toggle`).
- Parsarea și transformarea datelor pentru afișare dinamică în pagină.
