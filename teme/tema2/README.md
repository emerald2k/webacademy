# 📐 Tema 2: Flexbox & CSS Grid Mastery

O colecție completă de 17 exerciții practice pentru stăpânirea absolută a sistemelor de poziționare modernă: **CSS Flexbox** și **CSS Grid**.

---

## 🎯 Concepte Acoperite în cele 17 Exerciții

- **Flexbox Basics:** `flex-direction`, `justify-content`, `align-items`, `flex-wrap`
- **Flex Child Sizing:** `flex-grow`, `flex-shrink`, `flex-basis`, `align-self`
- **CSS Grid Basics:** `grid-template-columns`, `grid-template-rows`, `gap`
- **Fluid & Responsive Grids:** `repeat(auto-fit, minmax(...))`, `grid-area`
- **Centrare Perfectă & Layouts Dinamice:** Centrare orizontală/verticală, navigări adaptabile, carduri egale
