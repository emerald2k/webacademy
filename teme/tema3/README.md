# ✨ Tema 3: CSS Animations & Keyframes

Exerciții practice de creare a animațiilor CSS fluide, stăpânirea regulilor `@keyframes` și tranzițiilor interactive.

---

## 🎯 Concepte Cheie

- Declararea animațiilor cu `@keyframes` (procente de progres `0%`, `50%`, `100%`).
- Proprietăți CSS de animație: `animation-duration`, `animation-timing-function` (`ease-in-out`, `cubic-bezier`), `animation-iteration-count: infinite`, `animation-direction: alternate`.
- Efecte de hover, pulsații, rotiri și deplasări 2D/3D.

---

## 📂 Structură

- [`index.html`](./index.html) — Prezentarea animațiilor
- [`styles/`](./styles/) — Exercițiile de stilizare (`ex1.css` – `ex5.css`)
- [`demo.mp4`](./demo.mp4) — Previzualizare video a animațiilor în acțiune
