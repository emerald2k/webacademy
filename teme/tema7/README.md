# 📅 Tema 7: Interactive Calendar Application (Vite + CSS Grid)

O aplicație completă de calendar interactiv construită cu **Vite**, **JavaScript modern** și **CSS Grid**, optimizată pentru performanță de producție cu minificare **Terser**.

---

## 🎯 Funcționalități & Tehnologii

- **Generare dinamică a lunilor & zilelor:** Calcul automat al numărului de zile din lună și poziționarea primei zile a săptămânii.
- **Navigare temporară:** Butoane de navigare Înapoi / Înainte între luni și ani.
- **Layout CSS Grid:** Randarea grilei de 7 coloane reprezentând zilele săptămânii.
- **Configurare Vite:** Bundling cu `vite.config.js` și minificare avansată.

---

## 🚀 Rulare & Build

```bash
# Instalare dependențe
npm install

# Mod de dezvoltare
npm run dev

# Compilare pentru producție
npm run build
```
